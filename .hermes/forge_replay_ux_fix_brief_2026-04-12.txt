Сырой пользовательский фидбек, который нужно превратить в конкретные fixes:

1. Левый sidebar / Hermes archive / list surfaces
- Левая область с “Hermes archive” и всем ниже выглядит слишком generic / дешево.
- Selected/current conversation row обводится и выделяется дешево.
- Нужна UX-экспертиза именно по left sidebar selection, row density, hierarchy, hover/focus/current states.
- Нужно сделать аккуратнее, дороже, спокойнее, без дешевого border-selection feel.

2. User message bubble / “привет” выглядит слишком жирным и толстым
- User bubble/row сейчас слишком жирный, слишком здоровый.
- Нужно уменьшить визуальную тяжесть user messages, не ломая общую читаемость.

3. Active tasks / current turn / inspector semantics are unclear
- Пользователь не понимает:
  - что такое “Активные задачи”
  - откуда они берутся
  - каков их source of truth
  - что такое “Текущий ход” и зачем это нужно
- Если surface полезен — объяснить его в UI лучше и сделать понятнее.
- Если это UI noise — уменьшить/перестроить.

4. Model selection / provider / key management are unclear or missing
- Пользователь не понимает, как поменять модель.
- Пользователь не понимает, куда добавлять API key / model / provider, если понадобится.
- Нужно:
  - проверить, есть ли вообще доступный UX path для смены модели в replay UI;
  - если path есть, сделать его discoverable;
  - если path нет, добавить/вернуть понятный access path, но без dashboard drift.
- Нужно ответить product/UI-реализацией, а не только текстом.

5. Workspace/files behavior
- Workspace в целом стал лучше и выглядит хорошо.
- Но пользователь жалуется, что при открытии файлов появляется “обрезанный файл / кусок”, какая-то дичь в preview/presentation.
- Нужно проверить file preview / workspace content presentation и убрать broken/clipped presentation.
- Важно сохранить богатую workspace surface, уже возвращенную в replay baseline.

6. Archive semantics
- Пользователь не понимает:
  - архив общий или только по конкретному диалогу;
  - можно ли из архива добавлять в диалоги;
  - можно ли продолжать диалог из архива.
- Он увидел, что импорт/добавление, кажется, работает, и это ему нравится.
- Нужно сделать semantics и actions у архива предельно понятными в UI.

7. Skills surface is still bad
- Skills раньше были too large, сейчас too compressed/generic/ugly.
- Нужно переработать skills surface с помощью 21st.dev patterns:
  - аккуратные cards/rows
  - разные иконки по типам навыков
  - если это web/search skill — иконка лупы и т.п.
- Skills должны выглядеть polished, not generic.
- Обязательно не скатиться в redesign whole app.

8. Tool call / tool activity rows look dirty and unpolished
- Tool invocation surfaces все еще выглядят грязно/неаккуратно.
- Нужно сделать аккуратнее visual language tool rows / tool activity / operational surfaces.
- Пользователь явно на это жалуется.

9. Inspector / Profile / Skills / Memory / Overview / Todos surfaces are semantically unclear
- Пользователь не понимает:
  - как добавлять skill;
  - как добавлять memory;
  - рабочая ли вообще memory;
  - зачем нужен overview graph;
  - зачем нужен checklist/todos и как им пользоваться.
- Нужно не только styling, но и semantic UX cleanup:
  - clearer empty states
  - clearer actions
  - clearer explanations
  - where appropriate, add CTA/button/entry point
- “Overview” возможно слишком тяжелый, слишком линейный, занимает много места и может вызывать подвисания.
- Нужно критически оценить, нужен ли он в текущем виде, и если оставлять — сделать легче/понятнее.

10. Agent icon does not fit
- Иконка agent/age выбивается из стилистики.
- Пользователь хочет более монохромный, black/white compatible visual fit.
- Нужно заменить/адаптировать icon treatment so it fits the black-white theme better.

11. Settings / language surface issue
- В settings общий интерфейс выглядит прикольно.
- Но есть мелкие seams, например язык выпирает слишком сильно визуально.
- Нужно сделать settings surfaces более consistent/subtle where cheap and safe.

12. Preserve what user likes
- Текст ответов и типографика сейчас очень нравятся пользователю.
- Workspace в целом наконец-то нравится.
- Возможность тащить/import из archive ему нравится.
- Эти части не сломать.
